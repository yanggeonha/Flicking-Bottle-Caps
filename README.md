# 딱! 병뚜껑 챔피언십

핀 번호로 친구들과 접속해 즐기는 실시간 병뚜껑 멀리 보내기 게임입니다.

## 로컬 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 여세요. 두 개 이상의 창에서 각각 방 만들기/입장을 하면 멀티플레이를 확인할 수 있습니다.

## Render 배포

저장소를 GitHub에 push한 뒤 Render에서 이 저장소의 `render.yaml` Blueprint를 적용합니다.

> 방 정보는 서버 메모리에 저장됩니다. 무료 인스턴스 재시작 시 진행 중인 방은 초기화되며, 단일 인스턴스 실행을 전제로 합니다.
